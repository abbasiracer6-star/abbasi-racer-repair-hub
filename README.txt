ABBASI RACER — MOBILE REPAIR HUB
================================
Included:
- index.html, style.css, app.js
- assets/abbasi-racer-photo.jpg (provided image)
- Searchable sample brand/model navigation
- Hardware fault topic shortcuts
- Browser-session PDF upload and viewer
- Mobile-responsive layout

IMPORTANT:
This is a working starter website/interface, not a complete commercial schematic database.
The sample board artwork is decorative and is NOT an electrical schematic. No real model-specific
schematic PDFs, verified boardview data, or signal tracing database are bundled. Add genuine
schematic files that you are authorized to use. Verify model and board revision before repair.

HOW TO USE:
1. Extract the ZIP.
2. Open index.html in a browser to preview it.
3. For a public website, upload index.html, style.css, app.js, and the assets folder to the root
   of a GitHub repository. Enable GitHub Pages in repository Settings > Pages.
4. To view PDFs, use “Add schematic PDF” while the page is open. These uploads are local to the
   current browser session and are not permanently saved or uploaded to the website.
